- 选择理由：`^` 允许同一大版本内的补丁/次版本修复（安全更新），实际精确版本由 `pubspec.lock` 锚定，构建可复现；比硬写精确版本更利于后续升级。
- 未做任何降级凑包；4 个直接依赖均为 stable 最新兼容版本。

**原生构建增量**：`flutter_secure_storage 11.x` 通过 `jni` 触发 CMake 原生构建，AGP 自动安装 `cmake 3.22.1`（0.04 GB）。未新增 NDK 依赖声明，但 P0 探测工程构建时 AGP 已自动安装 NDK 28.2.13676358（2.12 GB），详见 §7。

## 3. 路由方案与理由

**选择：`go_router` + `StatefulShellRoute.indexedStack`。**

| 方案 | 结论 | 原因 |
|---|---|---|
| 手写 Navigator 2.0 + 5 个嵌套 Navigator + IndexedStack | 否 | 代码量大、返回栈与深链要手写；后续通知/扫码跳转成本高 |
| `go_router` ShellRoute（单 Navigator） | 否 | 单栈会丢失各 Tab 的滚动位置与二级页状态 |
| **`go_router` StatefulShellRoute.indexedStack** | **采用** | 每个 branch 独立 `NavigatorState`；切 Tab 只切 index；支持路径深链（P2 通知/扫码可用）；样板代码最少 |

实现要点：

1. `initialLocation = '/finance'`（方案：首装落财务）。
2. 5 个 `StatefulShellBranch` + 5 个 `GlobalKey<NavigatorState>`；每个分支根页 + 1 个二级页：
   - `/health` → `/health/records`
   - `/finance` → `/finance/transactions`
   - `/life` → `/life/notes`
   - `/invest` → `/invest/accounts`
   - `/settings` → `/settings/server`
3. 根页 `PopScope(canPop: false)`：根页按返回**不退出**（方案要求）；二级页默认 pop。
4. 重按当前 Tab：`goBranch(index, initialLocation: true)` → 回到该分支根页。
5. 顶栏：根页 `AppBar` 显示 Tab 全称 + 铃铛；二级页 `automaticallyImplyLeading` 显示返回 + 页面标题。

**未做**：「记住上次停留的 Tab」仍按方案留到 P2（首装固定财务，之后落上次 Tab）。

## 5. 网络层与本地存储（P1 只留接入点）

### 5.1 `ApiClient`（`lib/core/network/api_client.dart`）

- 两个 Dio 实例：`_dio`（业务请求，带拦截器）、`_refreshDio`（刷新专用，无认证拦截器，避免递归）。
- `get / post / put / delete` 统一返回 `Response<T>`；所有 `DioException` 统一转 `ApiException`。
- `baseUrl` 默认 `http://127.0.0.1:9015/api/v1`；`updateBaseUrl()` 去尾斜杠并同步两个 Dio 与 `ValueListenable`。
- 超时：连接 10s / 发送 15s / 接收 20s。

### 5.2 401 与 refresh 轮换（`auth_interceptor.dart`）

```text
请求 → 401（非 /auth/*、未重试） → 单飞刷新 POST /auth/refresh {refresh_token}
     → 响应 {access_token, refresh_token} → 两枚令牌同时写 secure storage
     → 用新 access 重放原请求一次（extra: auth.retried=true）
     → 刷新失败 → 清空令牌 → onSessionExpired 回调（P2 接登录页）
```

- **单飞**：并发 401 只发一次刷新（`_refreshInFlight`）。
- **轮换**：新 refresh 必须落盘（后端每次刷新轮换、365 天滑动），已实现。
- 真实登录接口尚未接入；调用点预留为 `ApiClient` 的四个方法。

### 5.3 存储

| 数据 | 实现 | Key / 文件 |
|---|---|---|
| access / refresh token | `flutter_secure_storage` 11.2.0（Keystore 加密） | `auth.access_token` / `auth.refresh_token` |
| 服务器地址 | `shared_preferences` 2.5.6 | `server.base_url`（实测落盘 `FlutterSharedPreferences.xml`） |
