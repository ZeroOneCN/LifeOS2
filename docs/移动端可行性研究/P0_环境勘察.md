### A.3 补齐前缺口清单

必须装：Flutter SDK（stable）、`cmdline-tools;latest`、`platforms;android-35`、`build-tools;35.0.0`、SDK 内 `platform-tools`。
建议装：Android Emulator + API 35 system image（约 6–10 GB）、Android Studio（约 3–4 GB）。
可选/不需要：JDK 21、Visual Studio C++ 桌面负载、Gradle 独立安装、Expo/EAS 账号。
NDK / CMake 已不是可选项：P1 构建 `flutter_secure_storage` 时由 AGP 自动安装（NDK 28.2.13676358 2.12 GB、CMake 3.22.1 0.04 GB），详见 §1 表格与 `P1_工程骨架.md`。

### A.4 补齐前安装顺序与预估

1. 下载 Flutter stable zip → 解压到 `C:\Env\flutter`（10–30 分钟，~1.5 GB）
2. 下载 cmdline-tools → `<SDK>/cmdline-tools/latest`（5–10 分钟）
3. 接受许可 + 装 platforms 35 / build-tools 35 / platform-tools（5–15 分钟）
4. 修正 `ANDROID_HOME` / `ANDROID_SDK_ROOT`，`flutter doctor -v` 复验（10–20 分钟）
5. 连真机或建 AVD
6. 首次构建拉 Gradle 发行版与依赖（10–30 分钟，+1–2 GB）

合计（无模拟器）约 30–60 分钟；磁盘建议预留 6–8 GB。

### A.5 补齐前网络坑与做法

pub.dev 偶发超时→当前会话设 `PUB_HOSTED_URL=https://pub.flutter-io.cn`；Flutter 下载慢→`storage.flutter-io.cn`；Gradle 发行版→直连优先；SDK 组件慢→`--proxy=http --proxy_host=127.0.0.1 --proxy_port=10090`（仅命令参数）；许可必须接受；`cmdline-tools` 目录名必须 `latest`；`ANDROID_HOME` 指向不存在目录→装到该路径；PATH 三条死路径装 SDK 后自动生效；不要用 CMD 936；JDK 若报 Unsupported Java 用 `flutter config --jdk-dir`；未装 Android Studio 警告可忽略。

### A.6 补齐前最短路径

装 Flutter → 装 cmdline-tools;latest → 接受许可并装 platforms/build-tools/platform-tools → 修正 `ANDROID_HOME`/`ANDROID_SDK_ROOT` 并 doctor 复验 → 连真机（或建 AVD）。预计 5 步、30–60 分钟。
