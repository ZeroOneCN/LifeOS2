硬性规则

  • 冷青只做导航与主操作，涨跌、收入支出永远用红绿，语义不混用。
  • 首屏只保留 1 个 Hero、1 条指标轨、≤2 个列表区，其余进栏目页。
  • 卡片不套卡片：同屏最多一层容器，层级靠底色与发丝线。
  • 数值等宽对齐：金额、步数、净值、百分比全部 tabular-nums。
  • 1.3x 字号不折行、不缩小：长文案进详情页，不在卡片里挤。
  • 加载保留旧数据：骨架只占位，不整页 spinner，不抖动。
