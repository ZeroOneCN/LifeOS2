本版决策

  • 下拉刷新为唯一刷新方式，顶栏不再出现刷新图标。
  • 通知不提升为一级入口，保留顶栏铃铛与设置内「通知中心」。
  • 快捷面板覆盖记账 / 购物 / 交易三种模式，高频记录不再跳整页。
  • 配色改为 iOS 系统色：System Blue 为唯一强调色，绿/红只表达涨跌与收支。
  • 顶部栏目统一 2 字：等宽文字轨道，蓝色短下划线选中，右侧渐隐提示可横滑。
  • 分组列表 + 16px 卡片：同屏不再卡片套卡片，分隔线左缩进 16。
  • 深浅色同构：深色使用纯黑底 + #1C1C1E 卡片，不改变层级结构。
